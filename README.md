# HOTEL-DEMO — The Highlands Boutique Hotel

A responsive, single-page hotel website concept built as a sales/demo project.

## Preview locally
Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. After GitHub Pages finishes deploying, the site should be available at:
   `https://gadbahati.github.io/HOTEL-DEMO/`

## Customize before using for a real hotel
- Replace the fictional hotel name, story, location, contact details and imagery.
- Replace the illustrative room names, facilities and sample KSh rates with verified hotel information.
- The booking forms create a WhatsApp enquiry; they do not check live room inventory or confirm reservations.
- On first enquiry, the demo asks for the hotel's WhatsApp number (with country code) and stores it in that browser's local storage.
- Images and fonts load from Unsplash and Google Fonts, so an internet connection is needed for those assets.

This is a concept/demo. It does not represent an actual hotel, its facilities, rates or availability.
